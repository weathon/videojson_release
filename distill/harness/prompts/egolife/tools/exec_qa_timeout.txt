Run bash or Python code in the sandbox like exec, then have another model read the code and its full output and answer a question about the output. Only that model's answer is returned. Useful when the output is too long to read directly.

language: "bash" or "python".
code: the code to run. Python code must begin with a docstring and bash code with a # comment that describes what the code does.
timeout_seconds: the time limit of the code, 1 to 600 seconds; the code is killed after it.
question: the question to answer from the output.
