Run bash or Python code in the sandbox and return its stdout and stderr. Python code must begin with a docstring that describes what the code does; bash code must begin with a # comment that describes what the code does. Every call starts a new process; files written under /work stay available to later calls. The code is killed after timeout_seconds. When the output is longer than 36000 characters it is not returned; change the code to print less, or use exec_qa. Such a call does not count toward your budget of model calls.

language: "bash" or "python".
code: the code to run.
timeout_seconds: the time limit of the code, 1 to 600 seconds.
