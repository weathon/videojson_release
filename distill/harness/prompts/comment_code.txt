Comment the code of every exec and exec_qa call chunk by chunk and line by line: a Python script starts with a docstring that says what it does, and every block of code (a loop, a condition, a group of lines that does one step) and every line that does something of its own has a # comment above it that says what it does and, where it is not obvious, why. Bash is commented the same way: a # comment above every command or pipeline.
